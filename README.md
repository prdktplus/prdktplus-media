# Prdkt+ Media Kit

The Prdkt+ Media Kit for partners and press: logos, colours, type and co-branding rules for Prdkt+, MENA's product community.

## Contents

- `index.html`: the Media Kit page (static, no build step)
- `assets/logo/`: downloadable logos (Latin primary/reverse as SVG + PNG, Arabic, MENA Product Summit)
- `assets/fonts/`: Poppins and IBM Plex Sans Arabic (self-hosted)
- `assets/js/`: React 18.3.1 and the page runtime, vendored so the site works offline

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
